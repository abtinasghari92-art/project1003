# Brand assets

Drop licensed files here (copied into both Next.js apps):

- `apps/*/public/brand/logo.png` — magazine logo
- `apps/*/public/brand/footer-ad.png` — footer ad banner
- `apps/*/public/fonts/peyda/Peyda-Regular.woff2`
- `apps/*/public/fonts/peyda/Peyda-Medium.woff2`
- `apps/*/public/fonts/peyda/Peyda-Bold.woff2`

Peyda is a commercial Fontiran typeface. Until the woff2 files exist, the UI falls back to Vazirmatn.
