# Fonts

Licensed w_Zar (W.Unicode) files used by the storefront:

- `W_Zar-Regular.woff2` / `.ttf` — body text
- `W_Zar-Bold.woff2` / `.ttf` — titles
- `W_Zar-Italic.woff2` / `.ttf` — italic
- `W_Zar-Kordi.woff2` / `.ttf` — Kurdish variant (not loaded in UI)

Brand guideline: تیتر `w_Zar Bold`، متن `w_Zar Regular`.
